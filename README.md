# 我的股票紀錄

這是一套可放到 GitHub Pages、以手機操作為主的台股／美股個人記帳 PWA。程式本身可公開當公版，但交易、股息、換匯、券商設定和分類只保存在每台手機的瀏覽器，不會自動上傳或跨手機同步。

## 目前功能

- 首頁極簡輸入：買入／賣出、股票名稱或代號、成交價、股數。
- 台股與美股分幣別計算，支援零股與美股碎股。
- 買進手續費納入加權平均成本；賣出損益扣除手續費與證交稅。
- 交易可回頭修改或刪除，修改較早紀錄後會依日期重算；舊內容保留在本機變更紀錄。
- 現金股利、股票股利與發放日可自行新增、編輯、刪除。
- 美元換匯可記錄實付／實收 TWD、USD、費用與實際匯率。
- 券商可自訂台股費率、折數、最低費及美股計費模式；股票、ETF、當沖稅率分開設定。
- 持股顯示股數、平均成本、持股成本、已實現損益、累計股息、分類配置與最近股息日。
- 月、年、全部及個股歷史報表；個股歷史包含已出清輪次、每筆交易後股數／均價、該筆已實現與報酬率。
- 可匯出／匯入完整 JSON 備份以便換手機；Tiingo Token 不會放入備份。
- 介面與已快取資料可離線使用。

獲利依台灣看盤習慣顯示紅色，虧損顯示綠色。沒有行情時，未實現損益會顯示「尚無價格」，不會錯當成零。

## Tiingo 是選用備援

Tiingo 只放在「設定」最下方作為美股日收盤價備援，預設關閉。未啟用時不會測試連線、不會自動查價，也不會影響記帳、股息、換匯或報表。

日後要用時才需要：

1. 到 [Tiingo](https://www.tiingo.com/) 註冊或登入。
2. 從官方 [API Token 頁面](https://www.tiingo.com/account/api/token)複製 Token。
3. 在程式的「設定 → 備援行情來源」主動開啟 Tiingo，再貼上 Token 測試。

Token 只存在設定它的裝置，不可寫進任何會提交到 GitHub 的檔案。Tiingo 目前不允許一般 GitHub Pages 網址直接從瀏覽器跨網域讀取，因此正式啟用前仍需加上自己控制的安全連線橋接，或取得 Tiingo 對網站來源的允許。不要把 Token 交給陌生的公用 CORS 代理站。

持股頁也可手動輸入最近收盤價；這不需要 Tiingo，適合先完成記帳與報表流程。

## 安裝到手機

網站須以 HTTPS 開啟，GitHub Pages 已提供 HTTPS。

- iPhone／iPad：Safari 開啟網站，點「分享」→「加入主畫面」。
- Android：Chrome 開啟網站，從選單選「安裝應用程式」或「加到主畫面」。

第一次開啟須連網下載程式。安裝完成後，已快取的介面可離線開啟；任何線上行情仍須網路。

## 部署到 GitHub Pages

1. 建立 GitHub repository，將本專案檔案放在 repository 根目錄。
2. 推送到 `main` 分支。
3. 到 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`。
5. 等 GitHub 顯示網址後，以手機開啟並加入主畫面。

所有資源使用相對路徑，因此也能放在 `https://帳號.github.io/專案名稱/`。

每次修改靜態程式後，要同步更改 `sw.js` 的 `SHELL_VERSION`，讓已安裝的手機取得新版本。Service Worker 只快取本站程式檔，不快取 Tiingo 等第三方 API 回應。

## 資料安全

- 不需登入，也沒有雲端同步；不同手機會有各自獨立資料。
- 清除網站資料、移除瀏覽器或使用無痕模式都可能使紀錄消失，請定期匯出備份。
- 匯入前程式會在同一瀏覽器保留一份匯入前快照；格式錯誤時不會覆蓋原資料。
- 程式不需要永豐銀行或券商帳號、密碼與下單權限。
- 行情僅供紀錄估值，可能受休市日、延遲、供應商修正或額度影響，不應作為下單報價。
