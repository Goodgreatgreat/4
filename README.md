# 慢慢記 · 全新手機投資帳本

這是獨立重寫的版本，不需要舊程式。不含私人 Excel 或交易資料。
暖色、大按鈕；主要功能集中在「記帳／我的股票／成果／資產」。

## 上傳 GitHub（第一次）

1. 解壓縮 `慢慢記-全新GitHub版.zip`，建立一個新的 GitHub 儲存庫，預設分支用 `main`。
2. 把解壓縮後的**內容**上傳到儲存庫最外層；最外層要看得到 `index.html`、`package.json`、`data` 和 `.github`，不要多包一層「全新版本」。勿上傳個人備份、Excel 或 Token。
3. 特別確認 `.github/workflows/pages.yml` 也已上傳。若拖曳漏掉隱藏資料夾，可用 GitHub「Add file → Create new file」建立這個完整路徑，再貼入同名檔內容。
4. 開啟儲存庫「Settings → Pages」，Source 選 **GitHub Actions**。不要選 Deploy from a branch。
5. 到「Actions → 更新官方台股行情並發布 → Run workflow」。第一次建立流程前若已自動執行失敗，在設定 Pages 後重新執行即可。
6. 成功後 Pages 會提供網站網址。用手機開啟，可加入主畫面；第一次須連網，之後可離線記帳。

這份交付尚未替你登入、上傳或發布到 GitHub。公開程式不等於公開帳本，但同一網站的程式可讀取該網站的本機資料：只使用自己信任的程式版本。

## 台股代號、名稱、ETF 與股價

- 輸入 `2330` → 台積電；`0050` → 元大台灣50。保留前導零，也接受全形數字及完整官方名稱。
- 建議清單會顯示名稱；股票提示同時顯示市場、商品類型、收盤價與**該檔行情日期**。
- 價格依同一個確切代號取用，不使用名稱的模糊搜尋結果。參考股價絕不覆蓋你輸入的成交價。
- 上市資料來自[證交所 OpenAPI](https://openapi.twse.com.tw/)，使用 `exchangeReport/STOCK_DAY_ALL`；上櫃來自[櫃買中心 OpenAPI](https://www.tpex.org.tw/openapi/)，使用 `tpex_mainboard_daily_close_quotes`。名稱採交易所公布的證券簡稱。
- 一般 ETF 與合資格被動債券 ETF 分開；被動債券資格依[櫃買中心 ETF 分類資料](https://info.tpex.org.tw/api/etfFilter?assetType=bond&etfStrategy=passive&rewardType=Vanilla)核對，不憑 B 字尾認定免稅。一般 ETF 的 00 代號規則只作商品辨識；查不到官方資料會提醒核對，仍可手動補登歷史股票。
- 公開日行情不一定涵蓋下市、停止交易、當天沒有有效成交價的商品。此版不是盤中即時串流，也不保證發布當天官方 API 已提供當天行情。
- GitHub 每個平日台灣時間約 17:17 重新抓取並發布；排程可能延遲，長時間無活動的公有儲存庫可能停用排程，請查看 Actions。手機開啟／回到網站時讀取發布資料，每次使用階段最多每小時自動讀取一次；「我的股票 → 更新股價」可立即重讀。
- 若官方來源／分類抓取失敗，部署流程停止，保留網站上次發布的版本，**不會把舊價日期改成今天**。Actions 成功不代表市場 API 已換日，請看每檔日期。

## 記帳與費稅

首頁主要填股票、成交價、股數。日期、帳戶、券商、費稅在展開選項。
台股及美股券商可個別新增並設為帳戶預設。每笔費稅會留在交易中；改設定不回頭改舊帳。

台股預設股票賣出 0.3%、一般 ETF 0.1%；符合資格的被動債券 ETF 停徵至 2026-12-31，之後暫按一般 ETF 設定試算。合資格現股當沖須自行選擇，適用期間為 2017-04-28 至 2027-12-31。依[財政部證券交易稅條例](https://law-out.mof.gov.tw/LawContent.aspx?id=FL006079)設定，未來修法需更新。實付費用與稅額可逐筆覆寫；歷史交易、特殊商品及券商進位方式以對帳單為準。

美股預設費稅 0 只是待設定，並非認定免稅。支援每筆、每股、成交額比例、最低費及賣出附加稅費；複雜上限／分項進位請填實付值。

現金股息填淨入帳金額和發放日；股票股利、分割也可記。分割不會自行更改股數，請在生效日補登。尤其回補跨越台股分割的歷史帳務時，未補分割會使市值及報酬錯誤。Tiingo 近期分割可提示確認，但不是完整歷史公司行動服務。

## 成本與報酬率規則

- 每個帳戶、每檔股票各算加權平均成本，買進費用計入成本；合併按鍵只彙總顯示，不把不同帳戶成本混在一起。
- 賣出淨收入 = 成交價 × 股數 − 實付費 − 實付稅。
- 此筆已實現損益 = 賣出淨收入 − 當時平均成本 × 賣出股數。
- 此筆／期間已售成本報酬率 = 已實現損益 ÷ 配對賣出成本。股息另列。
- 持股報酬率 =（參考收盤價 × 庫存股數 − 庫存成本）÷ 庫存成本。不預扣未來賣出費用。
- XIRR 把買進支出當負現金流、賣出及股息當正現金流，加上今天以最近可用收盤價估算的剩餘持股價值，以實際日期、365 日計算。台幣與美元分開；不是直接平均個股百分比。概念參考：[Portfolio Performance](https://help.portfolio-performance.info/en/concepts/performance/money-weighted/)。
- 未滿一年主要顯示期間資金加權報酬，短期年化藏在展開說明。缺行情、缺投入、同日現金流或多解風險會留白並說明。
- 這是**股票部位 XIRR**，不是包含閒置現金、換匯和外部存提款的整體帳戶 XIRR。月／年篩選的是實現損益與股息；年化欄明確採自開始記錄至今，不假裝有歷史月底估值。

## 總資產與換匯

資產頁合計台美持股、台幣／美元現金以及自訂資產。現金與其他資產是手動餘額快照，**交易不會自動加減現金**，請定期對帳。
可選配置範例後調整自己的目標比例和容許偏差。僅資產頁顯示超配／低配和差額，資料不完整時不計算調整額；不是個人化投資建議。

換匯買入／賣出紀錄獨立保留實際匯率與換匯成本。總資產美元估值匯率另外設定，不覆寫歷史換匯。**永豐即時匯率尚未自動串接**，可在「資產 → 更新資產」手動輸入你的永豐參考匯率與日期。換匯紀錄不等同證券帳戶實際美元現金餘額。

## Tiingo 是選用備援

預設關閉，在「設定與備份 → Tiingo」填自己的 API Token。它不是銀行登入密碼。Token 只存在該瀏覽器，不會包含在帳本備份或 GitHub 檔案。
GitHub Pages 直接連 Tiingo 可能遇到跨來源限制；可自行建立 Cloudflare Worker，貼入 `optional/tiingo-worker.js`，設定 `ALLOWED_ORIGIN` 為你的網站來源（例如 `https://你的帳號.github.io`，不含 `/儲存庫/`），再把自己的 `https://名稱.workers.dev` 填回程式。不要把 Token 傳給陌生中繼。也可以不啟用，直接手動輸入美股收盤。
需要你的帳號實測才能確認訂閱權限、額度及連線。本次沒有使用真實 Token 測試。

## 資料與更新安全

- 各手機／瀏覽器獨立，不同步、不提供雲端帳本。請勿使用私密瀏覽保存正式紀錄。
- 定期用「設定與備份 → 匯出備份」下載 JSON。換手機在同版程式匯入，會覆蓋新手機帳本並保留匯入前快照。
- 本機儲存不是加密保險箱。清除瀏覽器資料、更換網站來源或路徑，都可能找不到原帳本。先備份再更換網址。
- 舊程式與這次重寫的格式不同，**不直接相容**。原程式與原備份沒有被覆蓋；此版拒絕舊格式，避免錯誤搬移。
- 同帳戶同一天每筆順序需不同，可用 1.5 插入。編輯或刪除會重新檢查後續是否超賣，原內容留在變更紀錄。
- 離線程式更新在全部舊分頁關閉後生效。網頁首次下載完成前不能離線；手機是否允許安裝由瀏覽器決定。
- 月報在跨月後下次開啟時提示，不會在手機關閉網站時推播。

## 本機執行與驗證

安裝 Node.js 22 或以上，在此資料夾執行：

```sh
npm test
npm run build
npm run dev
```

預覽網址為 `http://127.0.0.1:4178/`。勿直接雙擊 HTML，模組／離線功能需要網站環境。
測試涵蓋官方代號、ETF 分類、費稅、帳戶隔離、成本、股息分割、XIRR、備份、行情與 Token 傳遞；未做手機實機或瀏覽器互動驗收。網站另提供可選 WebMCP 預填記帳工具，僅預填、不儲存；支援性仍由瀏覽器決定。
